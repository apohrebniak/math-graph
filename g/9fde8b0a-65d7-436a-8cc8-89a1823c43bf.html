Побудуйте графік функції:

y = (x - 2)² + 1

Базова функція: f(x) = x²

Параметри перетворення

Зсув по осі Ox (вліво / вправо): c = 0
Зсув по осі Oy (вгору / вниз): d = 0
Розтяг / Стиск / Відображення (a): a = 1
Модуль усієї функції |f(x)|:

Кроки перетворення:

    Режим Пісочниці Вільне дослідження

    Сконструйована формула:

    y = 1 · (x - 0)² + 0

    Довідник: Перетворення графіків

    1. y = f(x) + d

    Паралельне перенесення графіку вздовж осі Oy на |d| одиниць:

    • Якщо d > 0 — вгору
    • Якщо d < 0 — вниз
    2. y = f(x - c)

    Паралельне перенесення графіку вздовж осі Ox на |c| одиниць:

    • Якщо c > 0 (у формулі x - c) — праворуч
    • Якщо c < 0 (у формулі x + |c|) — ліворуч
    3. y = -f(x)

    Дзеркальне відображення графіку відносно осі Ox (перевертання за допомогою від'ємного коефіцієнта a = -1).

    4. y = a · f(x)

    Розтяг або стиск вздовж осі Oy у |a| разів:

    • Якщо |a| > 1 — розтяг від осі Ox
    • Якщо 0 < |a| < 1 — стиск до осі Ox
    5. y = |f(x)|

    Частина графіку, розташована нижче осі Ox, симетрично відображається в верхню півплощину.
